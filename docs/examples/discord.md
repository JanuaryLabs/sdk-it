# Build a Discord SDK

## Generate the SDK

Inside an existing TypeScript project:

```bash
npm install zod fast-content-type-parse

npx @sdk-it/cli@latest generate typescript \
  --spec https://raw.githubusercontent.com/discord/discord-api-spec/refs/heads/main/specs/openapi.json \
  --output ./src/generated/discord \
  --name Discord \
  --mode minimal
```

## Create the client

```typescript
import { Discord } from './src/generated/discord/index.ts';

const discord = new Discord({
  Authorization: `Bot ${process.env.DISCORD_BOT_TOKEN}`,
});
```

The generated client uses the specification's default
`https://discord.com/api/v10` server.

## Get the current bot user

```typescript
const user = await discord.request('GET /users/@me', {});

console.log(`Bot user: ${user.username}`);
console.log(`ID: ${user.id}`);
```

## Get guild information

```typescript
const guild = await discord.request('GET /guilds/{guild_id}', {
  guild_id: '123456789012345678',
  with_counts: true,
});

console.log(`Guild: ${guild.name}`);
console.log(`Member count: ${guild.approximate_member_count}`);
console.log(`Owner ID: ${guild.owner_id}`);
```

## Get guild channels

```typescript
const channels = await discord.request('GET /guilds/{guild_id}/channels', {
  guild_id: '123456789012345678',
});

console.log(`Total channels: ${channels.length}`);
for (const channel of channels) {
  console.log(`- ${channel.name} (${channel.type}): ${channel.id}`);
}
```

## Send a message

```typescript
const message = await discord.request('POST /channels/{channel_id}/messages', {
  channel_id: '123456789012345678',
  content: 'Hello from SDK-IT!',
  embeds: [
    {
      title: 'SDK-IT Discord Example',
      description: 'Sent with a type-safe client generated by SDK-IT',
      color: 0x3498db,
      fields: [
        {
          name: 'Documentation',
          value:
            '[Discord Developer Portal](https://discord.com/developers/docs)',
        },
      ],
    },
  ],
});

console.log(`Message sent: ${message.id}`);
```

## Create a channel invite

The Discord schema models this request body as a union, so its generated input
uses `$body`:

```typescript
const invite = await discord.request('POST /channels/{channel_id}/invites', {
  channel_id: '123456789012345678',
  $body: {
    max_age: 86_400,
    max_uses: 5,
    temporary: false,
    unique: true,
  },
});

console.log(`Invite created: https://discord.gg/${invite.code}`);
```

## Edit a guild role

```typescript
const role = await discord.request('PATCH /guilds/{guild_id}/roles/{role_id}', {
  guild_id: '123456789012345678',
  role_id: '123456789012345678',
  name: 'New Role Name',
  color: 0xff0000,
  permissions: 1_073_741_824,
  hoist: true,
  mentionable: true,
});

console.log(`Role updated: ${role.name}`);
```
